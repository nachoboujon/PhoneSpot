# Frontend

El frontend es estático y vive en `public/`. Las páginas HTML comparten `style.css` y `script.js`, donde se concentra la interacción con la API y el estado del cliente.

## Áreas de interfaz

- Catálogo y detalle: `catalogo.html`, `producto.html`.
- Compra: `carrito.html`, `checkout.html`, `compra-exitosa.html`.
- Cuenta: `register.html`, `login.html`, `recuperar.html`, `restablecer.html`, `perfil.html`.
- Operación: `admin.html`.
